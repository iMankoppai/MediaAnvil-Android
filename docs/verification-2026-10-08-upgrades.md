# 六项播放器升级验证（2026-10-08）

## 本轮改动

| 项目 | 已实现内容 |
| --- | --- |
| 播放状态保存 | 进度按音频独立存储，旧 JSON 进度自动迁移；队列仅在变化时保存；暂停不等待磁盘写入，服务销毁仍刷新待写数据；主页面首次设置读取移到 IO 线程。 |
| 大媒体库 | 专辑、歌手分组在后台计算，旧任务取消后不展示过期结果，计算期间显示加载状态。 |
| 封面 | 合并同一图片的并发请求；无封面结果缓存 60 秒（最多 512 条）；媒体扫描更新、标签编辑、重新选择封面时使缓存失效；长图按最长边缩放。 |
| 作品收听 | 文件夹详情显示整部进度、续播集数和单集进度，提供继续收听、下一集、多选以及批量完成/取消完成。 |
| 播放偏好 | 支持 0.5×；列表与作品页面多选批量设置/恢复倍速；文件夹保存默认倍速、续播回退和顺序/随机/列表循环；新集数沿用文件夹默认。单条倍速优先于文件夹，再使用全局值。新增按集数睡眠停止，只在自然结束时计数。 |
| 维护与测试 | 拆出歌单、分类浏览、歌曲行、播放控制组件；增加封面请求并发、长图缩放、作品进度及播放偏好测试；性能测量改为报告中位数、p95、最小值，并调用真实 SAF 查询入口。 |

作品与单条倍速设置包含在备份中，单条音频的倍速会随备份的文件重新匹配而迁移。作品默认设置按存储卷与文件夹路径识别；文件夹移动后应在新文件夹重新设置作品默认。

## 验证结果

- JVM 单元测试：140 个通过，0 失败、0 错误、0 跳过。
- 手机：vivo V2520A / Android 16。
- 原有功能与新增播放逻辑：62 个 instrumented 用例全部通过，包含真实 MediaStore 增删改移动、数据迁移与恢复、M4A 标签往返、区间循环、0.5× 与按两集停止。
- 作品页面：另外 1 个用例通过，使用 1000 条音频，验证滚到末尾、作品默认 0.5×、全选批量 1.25×、批量标记完成及整部 100% 进度。
- Debug APK 与 AndroidTest APK 构建通过。
- `lintDebug` 与 `lintRelease` 通过现有项目基线。仍保留基线问题及 4 个警告，未将其描述为零问题。
- `git diff --check` 通过。

原始手机记录位于 `build/device-regression-tests.txt` 与 `build/device-work-ui-tests.txt`，JVM 与 Lint 报告位于 `app/build/reports/`。

## 验证边界

重启持久化测试通过刷新写入并重建设置存储验证磁盘数据；不是完整模拟系统强杀、厂商省电策略或长时间待机。千集用例验证真实 Compose 滚动与批量操作，不作为滚动帧率基准。SAF 测量使用真实查询函数，未额外授予私人音频目录权限，不把无授权时的耗时当作大型授权目录性能。

为适配这部手机对后台测试界面启动的限制，增加了仅在 debug APK 中存在的测试 Activity；release APK 不包含该入口。测试结束后已重新打开 MediaAnvil 主页面。

## 使用入口

1. 播放页点倍速按钮选择 0.5×。
2. 歌曲列表长按进入多选，再点“设置倍速”。
3. 媒体 → 文件夹 → 作品，使用“继续收听”“下一集”“作品设置”“选择音频”。
4. 设置 → 睡眠定时 → 设置 → 按集数，选择停止集数（包含当前这一集）。
