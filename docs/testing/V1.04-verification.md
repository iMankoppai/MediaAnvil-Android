# V1.04 发布验证记录

测试日期：2026-09-23
设备：vivo V2520A（Android 16 / API 36）
工具链：JDK 17、Android SDK 36（Build Tools 36.0.0）、Gradle 9.6.0

## 为什么会有 1.04

1.03 已经发布（标签 `v1.03` → `71cce03`）之后，在做阶段三遗留项验证时发现了一个真实缺陷：

**通过文件夹授权保存的歌词，文件名被文件提供程序改写成了 `稻香.lrc.txt`。**

因为程序里其余部分都是**按文件名**工作的，这个多出来的 `.txt` 导致：

- `findSubtitle` 只找 `X.lrc` 和 `X.mp3.lrc` → **重新扫描曲库后找不到刚保存的歌词**
- `isSafeSubtitleName` 要求扩展名必须是 `lrc/srt/vtt` → **连自己写的文件都删不掉**

也就是说，1.03 正式版里「保存歌词」这个功能是**表面上成功、实际不可用**的。修好它必须发新版，于是有了 1.04。

### 4. 播放键形状（截图逐像素测量）

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 按钮尺寸 | 250 × 272 px（比例 0.919，**椭圆**） | **272 × 272 px（比例 1.000，正圆）** |
| 按钮下沿 | y = 2745 | y = 2681（**上移 64px = 16dp**） |

变形的原因：该行 5 个等权格子，360dp 屏幕上每格只有约 **62.4dp**，而按钮声明 68dp。`size()` 会遵守父级最大宽度，于是宽被压到 62.4dp、高仍是 68dp，`CircleShape` 就画成了椭圆。改用 `requiredSize()`（忽略传入约束）恢复正方形。
