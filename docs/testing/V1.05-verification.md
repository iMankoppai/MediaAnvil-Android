# V1.05 发布验证记录

测试日期：2026-10-06
设备：vivo V2520A（Android 16 / API 36）
工具链：JDK 17、Android SDK 36（Build Tools 36.0.0）、Gradle 9.6.0

## 本版包含的改动

本次发布是一次以「长音频收听体验」和「数据可靠性」为核心的优化，主要提交为 `27be9b7`。

| 分类 | 内容 |
| --- | --- |
| 扫描可靠性 | 区分「扫描失败」与「曲库为空」：媒体库查询全部失败时抛出 `ScanException`，保留上一次曲库并提示重试，不再静默清空；扫描与缓存写入串行化，避免旧结果覆盖新快照 |
| 长音频收听 | 睡眠定时最后 30 秒音量渐弱，触发或取消后恢复；播放页显示定时剩余分钟；速度 / 随机 / 循环改由播放服务统一恢复，通知栏、桌面组件、耳机入口状态一致 |
| 性能 | 封面缓存改为按真实内存占用限制（约 32 MB），列表封面解码为 160px 缩略图，播放页保持 1024px 大图；歌词 / 标签缓存 I/O 移出主线程 |
| 结构 | 歌词视图拆到 `LyricsView.kt`，通用组件拆到 `LibraryComponents.kt`；`NowPlayingPage` 1432 → 882 行，`LibraryPage` 1373 → 1154 行；统一筛选排序入口 |
