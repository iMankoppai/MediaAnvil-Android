这份记录对应本地临时构建 1.11；所有功能已合并到正式版本 1.0.8，GitHub 未发布此临时编号。

本版本增加在线歌词繁简转换与完整播放次数。

- 在线歌词预览增加“原文／简体／繁体”，选择后更新预览，保存当前选择的版本；记住上次选择，转换在本机后台执行。
- 每次选择从候选原文转换，保留 LRC 时间戳、偏移、元数据和换行，支持词语优先的繁简转换。
- 音频列表右侧增加“▷ 1次”样式的小标记，有完整播放记录时显示；未听完和手动标记已听完均不增加次数。
- 计数依据实际听过的连续部分与自然结束。暂停后继续、重启续听和倍速播放可完成同一次收听；单曲循环每完整一轮增加一次。
- 拖到结尾、跳过尚未听过的内容、手动切歌和仅循环 A–B 片段不算完整播放。
- 次数、未完成收听记录和歌词转换偏好纳入备份，恢复时跟随音频匹配迁移；旧备份不会擦除新计数。

版本：1.11（versionCode 12）。计数从本版开始记录，不推断旧版本历史。新的备份格式为 schema 5，本版继续支持读取 schema 1–4。

验证：150 项单元测试与 75 项手机回归测试通过，正式包签名及对齐检查通过。详见 [验证记录](../../verification-v1.11.md)。
