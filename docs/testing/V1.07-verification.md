# V1.07 验证记录

日期：2026-10-08。版本：`versionCode=8`、`versionName=1.07`。
设备：vivo V2520A，Android 16 / API 36。

## 功能变更

- 新建功能统一改为“区间标签”：开始、结束时间及标签文字必填，支持手动输入、毫秒时间和保存当前 A–B 区间。
- 支持编辑起止时间及文字、删除、跳到开头和循环播放。循环复用播放服务的 A–B 机制；从暂停状态开始循环时立即启动检查，避免等待原有空闲定时器。
- 旧单点书签及备注保留为待转换记录，结束时间由用户补充，不擅自生成区间。跨曲目切换会重置正在编辑的标签。
- 本地书签记录支持读取 v1 行及写入 v2 行；备份 schema 升到 4，仍可读取 schema 1–3。区间结束时间参与备份、跨设备重新匹配和恢复；旧版应用拒绝 schema 4，避免静默丢失结束时间。
- 开启 ExoPlayer 的 `setHandleAudioBecomingNoisy(true)`，音频从耳机转到扬声器时自动暂停。
- 列表增加文件夹浏览，按完整相对路径及存储卷区分；目录内自然排序，显示总集数、完成数量，支持整组播放。搜索包含目录文字。
- 移除“近期”入口，将“继续收听”改名为“续播”。历史记录继续保留、排序和备份；原有收听状态筛选保留，旧导航状态索引作边界处理。
- 通知提供器按上一曲、快退、播放/暂停、快进、下一曲排列。排序使用框架保留的图标信息，兼容 Media3 将标准播放器命令转换为会话命令的行为。

## 增量更新范围

- Android 11+ 按存储卷保存 MediaStore 数据库版本和 generation；版本相同、generation 未回退且扫描范围一致时复用缓存。
- 读取变化的音频元数据，合并新增、修改、改名及移动；仍读取轻量 ID 集合以发现删除。移动到范围外或变成不支持格式的变化记录会移除。
- generation 在查询之前捕获，扫描期间的新变化会在后续刷新重读，不跳过更新。
- 旧系统、缺少检查点、数据库重置、扫描范围变化、不支持增量查询及手动“完整重扫”使用完整扫描。
- 媒体库变更监听防抖 800 ms；扫描期间收到的新请求会排队，保留完整重扫请求。缓存及标签修改与扫描在同一个写入互斥区间协调。
- 增量指标只统计音频元数据行，不含轻量 ID 查询、SAF 歌词目录读取和 UI 绘制。本轮没有声明整体扫描耗时提升比例。

## 数据保护与验证边界

- 测试前保存调试应用 `files` 和 `shared_prefs`，结束后恢复并逐文件核对，3 个原有文件字节一致。
- 测试仅修改自建临时 WAV 和自建 MediaStore 记录，原有音频保留；区间标签不写入音频文件。
- 实体耳机断开尚未实测：设备拒绝 shell 发送受保护的断开广播，用户选择先完成其他验证。这不是自动化套件的跳过项。
- 本次不覆盖旧 Android 实体设备、跨存储卷挂载的实机行为、长时间耗电和采样级循环精度。区间循环采用约 250 ms 定时检查，支持毫秒时间输入不代表采样级循环。
- 手机解锁后完成真实界面复核：顶部仅保留列表、续播、收藏、歌单；续播的未开始、收听中、已听完筛选显示正常。文件夹入口识别 Music 目录，目录内列表及“播放此文件夹”入口显示正常。
- 播放页的区间标签入口、添加按钮、保存 A–B 区间按钮及编辑框均正常显示；标签文字、开始时间、结束时间、当前位置填入按钮和说明没有截断。此次视觉复核取消编辑，未新增标签，播放器保持暂停。
