# V1.06 验证记录

日期：2026-10-07。版本：`versionCode=7`、`versionName=1.06`。
本次完成下一版优先安排的三项：备份恢复、书签与继续收听、搜索与歌词目录扫描优化。

## 功能变更

- 备份 schema 3 包含逐曲进度、播放队列及当前索引、书签、完成状态和扫描/续播设置，保留 schema 1/2 的读取兼容。
- 新备份使用文件名、相对目录、大小、时长匹配音频；恢复前可检查结果并选择歧义候选。MediaStore ID 不作为跨设备身份，未匹配的数据及元信息会保留，以便复制音频后再次恢复。
- 导入大小限制为 16 MiB，先验证及匹配，再统一写入。恢复前等待播放服务暂停和保存，并暂时阻止旧进度回写；恢复后的队列保持暂停。
- 时间点书签支持添加、备注编辑、删除及点击跳转。“继续收听”显示百分比、剩余时长、最近收听时间，按近期顺序排列，支持三种状态筛选和手动完成标记。
- 续播可选回退 0/3/5/10 秒；暂停状态下的导出及服务关闭保留手动完成标记。
- 搜索索引和预排序放在后台复用，输入防抖 150 ms，过期查询可取消；文件名及标题使用自然排序。
- SAF 外挂歌词查找按目录批量读取，再在内存匹配，保留原有文件命名优先级。
- 修复新增书签按钮后播放页 A/B 文字换行，以及恢复后部分设置和播放模式显示不同步的问题。

## 性能测量口径

在 Debug 构建中预建索引，对 10,000 条音频进行 15 次三词搜索，全部 10,000 条匹配。
最终一轮中位数 7.933 ms，P95 47.353 ms。15 个样本的 P95 取最大值。
这只测索引建好后的查询，不含索引构建、扫描、UI 防抖等待、启动或列表绘制，不能直接与旧版包含排序的 86 ms 比较。
目录复用测试使用 10,000 个条目、2 个目录，确认只加载两次目录；这属于算法验证，未测实际 SAF 提供方耗时。
