# V1.02 真机冒烟测试

测试日期：2026-09-22  
设备：vivo V2520A  
系统：Android 16（API 36）  
安装包：Debug，versionCode 3 / versionName 1.02

## 结果

### 安装并启动 ✅

- APK 全量安装成功，`MainActivity` 正常进入前台。
- 首次进入显示存储权限用途说明，没有自动跳转系统设置。
- 用户触发授权后正确进入应用专属“所有文件访问”设置页。

### 媒体库扫描 ✅

- 授权后自动返回应用并扫描到 5 个本地测试音频。
- MP3、FLAC、WAV 均显示标题、歌手、格式和时长。

### 播放与自动切歌 ✅

- 点击 3 秒 MP3 后系统媒体会话进入 `PLAYING`。
- 短音频结束后自动切换到下一首。
- 完整播放页的封面占位、标题、歌手、进度和控制按钮显示正常。
- 暂停后系统媒体会话进入 `PAUSED`，继续播放后恢复 `PLAYING`。

### 播放队列 ✅

- 队列底部面板正常打开，显示 5 首歌曲。
- 当前歌曲高亮正确，“下一首播放”和移除按钮显示正常。

### 后台播放与通知 ✅

- 返回桌面后播放继续。
- 前台媒体服务通知存在，包含上一首、暂停、下一首、快退和快进五个操作。

### 队列与进度恢复 ✅

- 将第三首歌跳转并播放到约 122.3 秒，等待周期保存后强制结束进程。
- 重启应用后恢复同一首歌、完整 5 首队列，并在约 124.6 秒处保持暂停。

### 稳定性 ✅

- 测试期间未发现 `FATAL EXCEPTION`、ANR、`PlaybackException`。
- 测试结束时应用进程仍正常运行。
