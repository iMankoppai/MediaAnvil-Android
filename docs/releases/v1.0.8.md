本版本整合作品收听、批量倍速、媒体库性能优化、歌词繁简转换与完整播放次数，并统一使用三段式版本编号。

### 作品收听与倍速

- 新增 0.5× 倍速，多选音频后可批量设置倍速或恢复默认。
- 文件夹作品页提供整部进度、继续收听、下一集，以及批量标记已听完或未听完。
- 按作品记住默认倍速、续播回退秒数和播放顺序；单条音频设置优先于作品与全局设置。
- 睡眠定时支持“听完接下来 N 集停止”，暂停或手动跳集不消耗集数。

### 歌词与播放次数

- 在线歌词预览增加“原文／简体／繁体”，记住上次选择，在本机后台转换并保存当前预览版本。
- 转换保留歌词时间戳、偏移、元数据和换行，切换回原文恢复候选内容。
- 音频列表右侧显示“▷ 1次”式标记，完整听完才增加次数；暂停、重启后续听及倍速播放支持累计同一次收听。
- 完整单曲循环每轮增加一次；拖到结尾、跳过尚未听过的内容、手动切歌或仅循环 A–B 片段不增加次数。
- 次数、未完成收听记录和播放偏好纳入备份，并支持按音频匹配迁移。

### 媒体库与界面

- 修复首次授予音频权限后未自动扫描的问题，从系统设置返回时也能检测授权变化并自动加载。
- 播放进度分条保存，队列仅在变化时更新；分类计算与首次设置读取移到后台。
- 合并相同封面的并发请求，缓存短期无封面结果，改善缓存失效与超长图片缩放。
- 区间标签按钮简化为“手动添加”“从 A–B 添加”，时间使用分秒，旧标签边界保持兼容。
- 深浅色切换采用约 0.3 秒的画面淡入淡出，避免整个页面逐帧重组。
- 语言切换直接更新当前页面，避免重建界面造成闪屏。

### 版本与验证

- 对外版本为 **1.0.8**，GitHub 标签为 **v1.0.8**；保留本地临时 1.08–1.11 的全部功能。
- Android 内部安装序号为 versionCode 13，以便覆盖已安装的同签名临时版本。
- 151 项单元测试通过（含新增版本编号兼容测试），并沿用本轮功能的 75 项手机回归结果；正式包签名和对齐检查通过。
- 新备份为 schema 5，可读取 schema 1–4；历史播放次数不推算，计数从启用该功能后开始记录。
- 最低支持 Android 8.0（API 26），使用原正式签名，可覆盖同签名旧版而保留数据。

历史 GitHub 编号 1.01–1.07 对应 1.0.1–1.0.7。历史安装包保留原内容与包内编号，发布页注明对照；旧版更新器使用原比较规则，首次切换到三段式版本需要手动覆盖安装，新版已兼容历史编号。

完整构建与迁移验证见 [验证记录](https://github.com/iMankoppai/MediaAnvil-Android/blob/v1.0.8/docs/verification-v1.0.8.md)。
