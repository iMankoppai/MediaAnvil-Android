本版本重点改善播放恢复、更新安装可靠性和正式版发布流程。

### 播放与稳定性

- 合并保存播放进度、队列和当前曲目，应用退出时保存最终状态，改善重启后的恢复可靠性。
- 空闲时降低后台轮询频率，快速轮询仅用于 A-B 循环等需要及时响应的场景。
- 媒体库状态改为由 ViewModel 管理，并将播放队列面板拆为独立组件。
- 持久保存通过系统文件夹选择器授予的访问权限。

### 更新与发布

- 更新包下载后验证 SHA-256，校验通过才交给系统安装器；缺少配套校验文件的版本无法在应用内安装。
- 新增 GitHub 签名发布流程，自动执行测试、Lint、签名及版本检查，上传 APK 和 `.sha256` 文件。
- 修复 Gradle wrapper 的执行权限，确保 Linux CI 能正常构建。
- 更新 Compose 与 Media3 依赖，并补充存储权限和构建说明。

已在 vivo V2520A（Android 16）验证扫描、播放、自动切歌、队列、后台通知和进度恢复。

版本：1.0.2（versionCode 3）。最低支持 Android 8.0（API 26）。安装 Release 中的 APK，配套 `.sha256` 可用于完整性校验。
