本版本新增收藏、近期与有序歌单，并升级存储权限、数据保存和歌词加载。

### 新增与改进

- 新增收藏及最近播放列表；自定义歌单按添加顺序保存和播放，原有分组迁移为歌单。
- 移除“所有文件访问”权限：本地音频通过系统媒体库读取；保存歌词和编辑标签时，仅请求用户选择对应文件夹。
- 设置迁移到 DataStore，保留旧数据；串行保存设置，修复旧写入可能覆盖新值、导致最近播放记录丢失的问题。
- 统一歌词预览与播放解析，改善时间戳、小数秒、偏移及同时间戳原文/译文合并。
- 改善 UTF-8、UTF-16 和 GB18030 编码识别；对未关联、无权限、空文件、缺少时间轴等情况显示具体提示。
- 将媒体库缓存等磁盘操作移出主线程，并补充 UI、数据迁移、权限与歌词测试。

已验证 1.02 → 1.03 覆盖升级、旧分组迁移和签名连续性；真机完整测试套件 45 项通过，连续执行 3 次。

**历史已知问题**：部分文件提供程序会把保存的歌词命名为 `.lrc.txt`，影响重新扫描和删除；此问题已在 1.04 修复，建议使用较新版本。

版本：1.03（versionCode 4）。最低支持 Android 8.0（API 26）。可覆盖升级 1.02，无需卸载。
