本版本完善本地长音频收听体验，并增强备份恢复与大媒体库搜索。

### 新增与优化

- **备份恢复**：备份包含播放进度、队列、书签、完成状态及播放器设置；支持按文件名、相对目录、时长和大小重新匹配音频。恢复前可预览结果，同名歧义文件可手动选择，暂未匹配的记录会保留。兼容旧版备份。
- **书签与继续收听**：可添加时间点书签、编辑备注并点击跳转；按最近收听顺序查看进度、剩余时间，筛选未开始、收听中和已听完的音频；支持手动标记完成及恢复播放时回退 0、3、5 或 10 秒。
- **搜索与扫描**：复用后台搜索索引、输入防抖和取消过期查询；标题与文件名按数字自然排序；外挂歌词扫描复用目录索引，减少重复读取。
- 调整播放页按钮布局，并改善备份恢复后的播放状态和设置同步。

### 验证与安装

- GitHub CI 已通过 122 项单元测试及 56 项 Android 测试，均无失败、错误或跳过；已完成手机验证，发布流程再次运行 Android 测试、单元测试和 Lint。
- M4A 标签写入固定在 Android 上验证，检查中文标签、其他标签及音频内容保持完整；自动测试拒绝跳过，并要求该专项实际通过。
- 安装下方 `MediaAnvil-v1.06.apk`，可覆盖升级；配套 `.sha256` 文件用于完整性校验。
- 最低支持 Android 8.0（API 26），版本号 1.06，versionCode 7。

备份不包含音频、歌词或封面图片本身；换设备时需复制这些文件并重新授予目录访问权限。文件匹配使用元信息，同名、同大小、同时长的候选需人工确认。
