本版本修复媒体通知与应用更新检查，并补齐项目构建入口。

### 修复

- 修复未申请通知权限导致 Android 13+ 上通知栏及锁屏播放控制无法显示的问题。
- 更新检查改为读取本 Android 仓库，修复误指向 Windows 版仓库的问题。
- 通知权限申请改为从“所有文件访问”设置页返回后触发，避免与系统界面冲突。这是 1.01 的历史行为，后续版本已调整存储权限方案。

### 改进

- 区分“尚未发布版本”和“网络故障”，使更新检查的失败提示更准确。
- 补齐 Gradle wrapper，克隆项目后可直接构建。
- 修正 README 中的构建路径与 Gradle 版本说明。

版本：1.01（versionCode 2）。最低支持 Android 8.0（API 26）。
